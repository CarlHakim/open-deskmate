# Answer Actions

Chat, Build, and helper transcripts provide actions under supported answers. Use them to keep useful work or prepare a follow-up.

| Action | What happens next | What is saved or sent? |
| --- | --- | --- |
| Useful | Toggles a personal marker on that answer. | Saved on this device for ordinary tasks; incognito markers stay in memory. It does not train or automatically instruct the model. |
| Explain more | Adds a contextual explanation request to the draft. | Nothing is sent until you use Send/Run. |
| Try another direction | Adds an alternative-approach request to the draft. | Existing draft text is preserved; review it before sending. |
| Save this approach | Opens an editable reusable-prompt template based on the answer. | Saved to the prompt library after confirmation. |
| Save to scrapbook | Opens a project save dialog for a reference snapshot. | Saved as a project Workboard item shown in Scrapbook. |

## Ask For More Detail

1. Find the answer you want to discuss.
2. Click **Explain more** or **Try another direction**.
3. Review the prepared follow-up, including any existing draft text.
4. Edit the request and click **Send/Run**.

The prepared request references the selected answer and its original request. Long references may use excerpts. In a helper transcript, follow-up answer actions target the helper composer rather than the main agent.

## Save An Approach As A Template

1. Click **Save this approach**.
2. Choose a name and category.
3. Edit the template, including the new-task placeholder and example answer.
4. Save and wait for confirmation.
5. Find it later in the prompt library or **All actions**, where you can pin it.

Cancel, X, Escape, or click outside to dismiss the dialog. If saving fails, edits remain for retry. Saving during incognito explicitly retains the edited template.

## Choose The Right Kind Of Saving

- Use **Useful** for a personal marker.
- Use **Save this approach** for instructions you want to reuse on another task.
- Use **Save to scrapbook** for project reference material.
- Use existing note/RTF export actions for documents and rich project notes.
- Use **Save as skill** for a completed workflow that should become a reusable skill.
