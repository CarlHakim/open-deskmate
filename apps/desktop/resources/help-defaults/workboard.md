# Workboard

The Workboard is a per-project work tracker inside Project Management and the floating project work popup.

## When To Use It

Use the Workboard when you need to track project tasks, checklist progress, notes, drawings, documents, dates, assignees, or status across a budget project.

## Quick Steps

1. Open **Project Management** or the floating project work popup.
2. Select the project.
3. Open **Workboard**.
4. Choose **Table**, **Kanban**, **Timeline**, or **Calendar**.
5. Create a work item or open an existing one.
6. Add lists, checklist items, notes, drawings, documents, assignees, dates, and status.
7. Save the work item.

## Step-By-Step: Create A Kanban Work Item

1. Open the **Kanban** view.
2. Create or select the list/state where the item should start.
3. Add the work item title.
4. Choose a color badge if the item should stand out.
5. Open the item to add details, checklist lists, notes, drawings, and documents.
6. Add assignees and due dates where useful.
7. Move the item between lists as work progresses.

## Views

- **Table**
  - Dense list of work items with status, priority, assignees, dates, source, and budget context.
- **Kanban**
  - Board grouped by project states.
  - Add, rename, reorder, and configure lists/states.
  - Move work through states.
- **Timeline**
  - Date-based view for work items with start or due dates.
  - Choose 1 month, 3 months, 6 months, 1 year, or a custom range.
- **Calendar**
  - Calendar-style date view for scheduled work.

## Work Items

Each work item can include:

- Title and description.
- Color badge.
- Source, such as a Chat project, Chat task, Build preset, or Build session.
- State/status.
- Priority.
- Assignees.
- Start date and due date.
- Checklist lists and checklist items.
- Rich notes.
- Drawings.
- Document links.
- Tags and blocked state.

## Checklists

Checklist items can have:

- Done checkbox.
- Assignee.
- Due date.
- Delete action.

Each list and work item shows completion percentage based on checked checklist items.

## Notes

Work item notes support rich text:

- Headings.
- Bold, italic, underline.
- Bullet and numbered lists.
- Quotes.
- Tables.
- Links.

Notes can be edited, deleted, popped out, and shown full screen.

## Drawings

Drawings support:

- Freehand drawing.
- Lines and arrows.
- Rectangles, ellipses, and triangles.
- Text.
- Stroke color, fill color, transparency, stroke style, and thickness.
- Resize, move, duplicate, delete, undo, redo, zoom, popout, fullscreen, and SVG export.

Exported drawing filenames include date and time.

## Documents

Documents can link to:

- Local files.
- Local folders.
- Web URLs.
- Google Docs links.
- Microsoft 365 links.

If a local file is moved, the link can break. Use edit/relink to update the document link.

## Troubleshooting

- If a work item is missing, check the selected project and active state filters.
- If a document link does not open, confirm the file has not moved or the web link is still valid.
- If note formatting looks wrong, use the rich text toolbar and the copy action built into the note popout.
- If a drawing export is hard to find, check the chosen export folder and timestamped filename.
