# Settings: Mobile Node Companions (Pilot)

Pair mobile devices as companion nodes for camera/mic/screen capabilities.

## Key Settings

- **Enable mobile nodes**
  - Turns companion node support on/off.
- **Display name**
  - Friendly node label.
- **Pairing endpoint URL**
  - URL used by companion clients to initiate pairing.
- **Companion URL**
  - Mobile web companion page.
- **Pending requests**
  - Approve or reject pair requests.
- **Paired nodes**
  - Manage existing nodes (name, status, access, etc.).

## Typical Flow

1. Enable mobile nodes.
2. Open/copy companion URL on the phone.
3. Approve pairing request.
4. Use camera/mic/screen tools for paired node.
