# Settings: Mobile Node Companions (Pilot)

Pair mobile devices as companion nodes for camera/mic/screen capabilities.

## When To Use It

Use this section when you want a phone or other mobile device to provide camera, microphone, or screen input to the app.

## Key Settings

- **Enable mobile nodes**
  - Turns companion node support on/off.
- **Display name**
  - Friendly node label.
- **Pairing endpoint URL**
  - URL used by companion clients to initiate pairing.
- **Companion URL**
  - Mobile web companion page.
- **Pending requests**
  - Approve or reject pair requests.
- **Paired nodes**
  - Manage existing nodes (name, status, access, etc.).

## Quick Steps

1. Enable mobile nodes.
2. Open/copy companion URL on the phone.
3. Approve pairing request.
4. Use camera/mic/screen tools for paired node.

## Step-By-Step: Pair A Mobile Device

1. Open **Settings > Mobile Node Companions**.
2. Enable mobile nodes.
3. Copy or open the companion URL on the mobile device.
4. Submit the pairing request from the device.
5. Approve the pending request in Settings.
6. Rename the paired node if needed.
7. Test the intended camera, microphone, or screen capability.

## Troubleshooting

- If the phone cannot open the URL, confirm both devices can reach the same network endpoint.
- If no pending request appears, refresh the page and confirm mobile nodes are enabled.
- If a paired node is unavailable, check device network, browser permissions, and node status.
- If public access is needed, review **Settings > Automations** endpoint settings.
