# Settings: About

General application info and utility actions.

## When To Use It

Use this section when you need the installed app version, platform details, repository links, or diagnostic context for support.

## Quick Steps

1. Open **Settings > About**.
2. Check the app version and platform details.
3. Use the project or support links if needed.
4. Include the version and platform when reporting a bug.

## Typical Content

- App name/version/build information
- Platform details
- Project/repository references
- Utility links or support actions
- Installed app version shown to the user
- Diagnostic context that helps compare local behavior with a reported issue

## Notes

- If you are sharing diagnostics, include version and platform from this section.
- Use [Doctor](./doctor.md) and [Developer](./developer.md) together for technical troubleshooting.
- If the About section is missing version details, update the app and restart before reporting the issue.

## Troubleshooting

- If version details are missing, restart the app and reopen About.
- If a support link does not open, copy the visible URL if available.
- If you are diagnosing a bug, run **Doctor** and include those results with the About details.
