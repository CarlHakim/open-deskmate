# Settings: Memory (User Context)

Edit the user/agent memory notes used for context.

## When To Use It

Use this section when the app should remember stable preferences, current goals, daily status, or personal context across tasks.

## Quick Steps

1. Open **Settings > Memory (User Context)**.
2. Add stable preferences to long-term memory.
3. Add temporary goals or current status to daily memory.
4. Choose the date when editing daily memory.
5. Save changes.
6. Start a task and confirm the agent uses the intended context.

## Key Settings

- **Long-term memory**
  - Durable notes and stable preferences.
- **Daily memory**
  - Date-specific notes and temporary context.
- **Date selector**
  - Opens/saves memory for a specific day.

## Suggested Usage

- Put evergreen policies in long-term memory.
- Put current objectives/status in daily memory.
- Keep entries concise and structured for better retrieval.

## Troubleshooting

- If the agent ignores memory, check whether the active agent includes memory context.
- If stale context appears, remove or update old long-term memory.
- If daily context is wrong, check the selected date.
- If memory grows too long, summarize it into short bullet points.
