# Settings: Memory (User Context)

Edit the user/agent memory notes used for context.

## Key Settings

- **Long-term memory**
  - Durable notes and stable preferences.
- **Daily memory**
  - Date-specific notes and temporary context.
- **Date selector**
  - Opens/saves memory for a specific day.

## Suggested Usage

- Put evergreen policies in long-term memory.
- Put current objectives/status in daily memory.
- Keep entries concise and structured for better retrieval.
