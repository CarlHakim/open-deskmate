# Settings: API usage estimate

Configure pricing inputs used to estimate token spend.

## Key Settings

- **Currency**
  - Global currency for display.
- **Provider/model pricing rows**
  - Input price per 1M tokens.
  - Output price per 1M tokens.
  - Optional effective-from date.
- **Inherited pricing**
  - Model-level rows can inherit provider-level defaults.

## Purpose

This section affects estimate/reporting displays. It does not change provider billing.

## Tips

- Use official pricing docs for each provider/model.
- Set effective dates when pricing changes over time.
