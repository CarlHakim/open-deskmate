# Saved Prompts And Recipes

Saved prompts and recipes help you reuse instructions in Chat Mode and Build Mode.

## When To Use It

Use saved prompts and recipes when you repeatedly ask for the same kind of work, such as research summaries, Build fixes, Git checks, automation drafts, file processing, or troubleshooting.

## Quick Steps

1. Open a Chat or Build prompt.
2. Click the saved prompt/recipe button.
3. Search or choose a category.
4. Select the prompt or recipe.
5. Review the inserted text.
6. Edit anything specific to the current task.
7. Send the prompt.

## Step-By-Step: Create A Saved Prompt

1. Open **Settings > Saved Prompts & Recipes**.
2. Choose **New prompt**.
3. Enter a clear prompt title.
4. Choose the category where it should appear.
5. Enter the prompt content.
6. Save the prompt.
7. Return to Chat Mode or Build Mode and insert it from the prompt picker.

## Built-In Recipes

Recipes are bundled prompt templates grouped by category.

Categories include:

- Build.
- Research.
- Automation.
- Files.
- Connectors.
- Troubleshooting.

## Saved Prompts

Saved prompts are user-created prompts.

They use the same category system as recipes so the prompt picker stays consistent.

## Where To Use Them

- Chat Mode initial prompt.
- Chat Mode follow-up prompt.
- Build Mode prompt.
- Build Mode current prompt save button.

## Managing Categories

Use **Settings > Saved Prompts & Recipes** to:

- Create saved prompts.
- Edit saved prompts.
- Delete saved prompts.
- Add categories.
- Rename categories.
- Delete categories and move prompts to another category.

The Manage saved prompts popup can send you to Settings when you need category management.

## Tips

- Keep reusable prompts specific.
- Use categories for work type, not for individual clients.
- Use Project Management for client/project organization.

## Troubleshooting

- If a prompt count looks wrong, open Settings and confirm whether you are looking at saved prompts, bundled recipes, or both.
- If a category appears empty, check the active filter and search text.
- If you need to rename or delete a category, use Settings rather than the compact prompt picker.
- If a Build prompt picker only shows Build prompts, check whether the picker is filtering by mode.
