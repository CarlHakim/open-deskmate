# Live Agent Team And Character Cards

The **Background work** panel in Chat and Build shows the coordinating agent and tracked helpers. Use it when a task delegates work and you want to understand who is doing what.

## Inspect The Team

1. Expand **Background work** in the task view.
2. Read each helper's assignment, recorded status, and latest activity.
3. Select the helper's name or assignment to open its transcript and follow-up controls.
4. Click an avatar to open a character card.

Multiple helpers can use the same agent profile and avatar. They remain separate runs with different assignments and run IDs. A short handoff indicator can appear as results are delivered; it does not mean their findings have been independently verified.

## Use A Character Card

You can open cards from the journey, current activity, team avatars, and supported answer avatars. A card shows configured identity and capabilities, the current or latest assignment, and recent recorded contributions.

- Main-agent contribution links jump to their messages in history.
- Helper contributions open that helper's transcript.
- **Progress & guidance** opens the helper's existing supervision controls.
- **Open prompt box** focuses the main composer without inserting or sending anything.

Cards float over the page. Use **X**, Escape, or click outside to close them. Configured capabilities describe what the profile can use; they are not proof that a particular tool ran or that an external service is connected.

## Follow Up Or Recover

Reusable open helper sessions can accept follow-up prompts. Stop, archive, close-session, diagnose, recovery, and replacement controls remain available through the tracked run details. See [Subagents](./subagents.md) before deciding which action you need.

## What Is Saved?

Assignments, reports, run history, and delivery states come from the tracked task records. Opening a card or transcript does not spawn another agent. Closing a card does not stop its run.

## Troubleshooting

- If no helpers appear, check **Settings → Agents → Subagents** and whether this task actually delegated work.
- If an avatar looks duplicated, compare assignments and run IDs.
- A missing capability or report is shown as missing; do not assume the helper completed work merely because its profile lists that capability.
