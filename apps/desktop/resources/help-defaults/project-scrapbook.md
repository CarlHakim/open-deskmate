# Project Scrapbook

Open **Project Management**, select a project, and choose **Scrapbook**. It brings the project's Workboard notes, document/image attachments, and source links together as visual cards.

## Save An Answer

1. Under an answer in Chat, Build, or a helper transcript, click **Save to scrapbook**.
2. Select the project, or create one if needed.
3. Enter a useful title and optional note, and review the snapshot.
4. Save and wait for confirmation.
5. Open that project's **Scrapbook** to find it.

This creates an ordinary Workboard item tagged for Scrapbook, including the original task or Build-session link when available. Saving a helper answer retains the helper's source identity. Saving during incognito explicitly keeps the saved item.

## Add Other Material

Use **Add item** in Scrapbook to add a note or decision, local files/images, or a web link. Existing Workboard material also appears; you do not need to duplicate it. Archived work items are excluded.

Search by text, use the type filters, and mark favorites to find material again. Favorites are saved on this device. Large collections initially show a limited set; use **Show more** for additional cards.

## Open And Edit A Card

1. Click a card to read the complete note or inspect its image.
2. Use **Open original** for its source file or link.
3. Use **Open linked task** to return to the recorded conversation when available.
4. Use **Edit in Workboard** to edit or archive the underlying item.

Local files remain linked at their existing locations; moving or deleting one can make it unavailable. A saved answer is a snapshot, not a live view of later edits to the conversation. Remote images open on demand.

Interactive budgets, checklists, and comparisons in a saved note have their own local display state. Saved guidance choices do not submit tasks. Do not treat unsaved widget adjustments as edits to the stored note.

## Scrapbook Or Prompt Library?

Scrapbook stores project reference material. **Save this approach** stores a reusable prompt template in the library. Neither action changes a project's spending budget or starts the agent.

## Troubleshooting

- Missing item? Check the selected project, search/type filters, and whether its Workboard item was archived.
- Missing image? Use **Open original** and confirm the local file still exists.
- Save failed? Keep your edits in the dialog and retry after checking the error.
- No original-task link? Older or manually added items may not have a recorded task association.
