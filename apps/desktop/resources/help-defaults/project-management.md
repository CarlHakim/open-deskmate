# Project Management

Project Management is the place to organize work by budget project, client, owner, assignees, work items, and usage.

Open it from the briefcase icon near Settings.

## When To Use It

Use Project Management when you need to organize real work around a client, internal project, budget, assignee, workboard, note, drawing, document, or usage report.

## What A Project Is

A Project Management project is a manual usage/budget project. It is separate from:

- Chat Mode task projects in the left sidebar.
- Build Mode project presets.
- The workspace folder on disk.

You can attach those items to a Project Management project so their usage, work items, notes, documents, and drawings stay grouped together.

## Main Areas

- **Usage projects list**
  - Select, create, archive, or restore budget projects.
  - This list stays visible while the selected project content scrolls.
- **Overview**
  - Quick status, spend, token totals, attached Chat/Build work, and read-only budget details.
- **Analytics**
  - Spend over time, token mix, model usage, budget health, and top work items.
- **Workboard**
  - Table, Kanban, Timeline, and Calendar views for project work items.
  - Create lists, notes, drawings, documents, prompts, and CSV exports.
- **Work**
  - Budget contents and assignment tools for Chat projects, direct Chat tasks, Build presets, and Build sessions.
  - Move work between budgets or remove work from budget tracking.
- **Assignees**
  - People directory, workload overview, budget defaults, and assignment overrides.
- **Budgets**
  - Budget windows for dated money/token limits.
- **Usage**
  - Per-window and total cost/token summaries.
- **Details**
  - Client name, project code, owner, billing fields, links, tags, priority, and due date.
- **Notes**
  - Project-level notes with dates.

## Budget Contents

The Work tab shows what is currently attached to the selected budget:

- Chat projects from the Chat Mode sidebar.
- Direct Chat tasks that are not inside an attached Chat project.
- Build presets.
- Build sessions.

Use the budget dropdowns to move work to another budget or remove it from tracking.

Direct Chat tasks are included so a task with a selected project still appears even when it is not inside a Chat Mode sidebar project.

## Work Assignment

Use **Assign existing work** when you want to attach or move existing work.

The assignment table can be filtered, resized, and exported. Hover over shortened names or context values to see the full text. Use column visibility when you need a smaller table.

If a Build preset is assigned to a budget, new Build sessions from that preset inherit the budget. If only a single Build session is assigned, the preset itself remains unassigned.

## Quick Steps

1. Create a project.
2. Add budget details such as client, owner, billing reference, due date, and tags.
3. Assign Chat projects, direct Chat tasks, Build presets, or Build sessions.
4. Add budget windows if you want warnings or blocking limits.
5. Use Workboard to track tasks, notes, drawings, and documents.
6. Review Analytics and Usage to see spend and token behavior.

## Step-By-Step: Attach Existing Work

1. Open **Project Management**.
2. Select the usage project in the left list.
3. Open the **Work** tab.
4. Expand **Assign existing work** if it is collapsed.
5. Find the Chat project, direct Chat task, Build preset, or Build session.
6. Choose the target budget from its dropdown.
7. Confirm it appears under **Budget contents** for that project.

## Troubleshooting

- If a Chat task does not appear under Budget Contents, check whether it is directly assigned to the budget or inside a Chat project that is assigned to the budget.
- If a Build preset does not appear, confirm the preset itself has a budget, not only one of its sessions.
- If usage appears unpriced, add or fix pricing rows in **Settings > API usage estimate**.
- If the left project list scrolls with the right panel, reopen Project Management after updating the app.
- If a direct Chat task is missing, confirm the task itself has a project selected or that its Chat project is attached to the budget.
