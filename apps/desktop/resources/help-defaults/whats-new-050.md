## A Short Tour

1. In Chat or Build, open **More options** to find secondary prompt controls. Close it with **Close**, Escape, or a click outside.
2. Open **All actions**, choose an action, and click **Add to prompt**. Review the draft before sending it.
3. While the agent works, open a stage in the **Task journey** or a helper in **Background work**.
4. Under an answer, try **Useful** or **Save to scrapbook**.
5. Use **Focus** for more reading room, or the journey's sliders button to change interaction appearance.

## Compact Build Prompt

![The compact Build prompt with Run, project selection, More options, action overflow, and context indicator.](./assets/build-composer-050.png)

The input starts at two lines, grows as you type, and has an expand button for longer drafts. **Run** becomes **Stop** during agent work. The separate preview controls still manage the project runtime.

## What Does A Click Save Or Run?

- **Add to prompt**, guidance choices, **Explain more**, and **Try another direction** prepare a draft. Use **Send/Run** to ask the agent to act.
- Interactive quantity controls and checkboxes change the displayed answer locally. They do not change project spending limits.
- **Save this approach** saves a reusable prompt template; **Save to scrapbook** saves a project reference.
- **Useful** records a personal marker. It does not train the model.
