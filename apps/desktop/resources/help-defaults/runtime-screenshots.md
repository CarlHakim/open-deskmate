# Runtime Screenshots

Runtime screenshots are available in Build Mode when Runtime Preview is active.

## When To Use It

Use runtime screenshots when you want to show the AI a visual problem, save a preview state to project work, or export a marked-up screenshot for another person.

## Quick Steps

1. Open **Build Mode**.
2. Start or refresh Runtime Preview.
3. Choose the screenshot button.
4. Select **Capture area** or **Full preview**.
5. Annotate the screenshot if needed.
6. Attach it to the current prompt, export it, or save it to a project work item.

## Step-By-Step: Capture A Selected Area

1. Click the screenshot button while Runtime Preview is active.
2. Choose area capture.
3. Drag over the part of the preview you want.
4. Use the visible rectangle, clear center, handles, and size label to confirm the selection.
5. Release the mouse to capture.
6. Add arrows, shapes, text, or freehand marks.
7. Attach, export, or save the screenshot.

## Screenshot Modes

- **Select area**
  - Drag over the preview.
  - The outside area dims and the selected rectangle stays clear.
  - The selection has a visible border, handles, and live size label.
- **Full preview**
  - Captures the full preview page, including content that requires scrolling when supported.

If Runtime Preview is not active, the screenshot button is disabled.

## After Capture

The screenshot opens in the annotation editor.

You can:

- Draw freehand.
- Add lines and arrows.
- Add rectangles, ellipses, triangles, and text.
- Move, resize, duplicate, select, and delete items.
- Change stroke color, fill color, transparency, line style, and thickness.
- Undo and redo.
- Zoom in and out.
- Open fullscreen.

## Output Options

You can:

- Attach the screenshot to the current Build prompt.
- Export it to a chosen location.
- Save it to a project work item as a document link.

## Tips

- Use area capture for focused visual feedback.
- Use full preview capture when you need to preserve a whole generated page.
- Add text labels or arrows before attaching the screenshot to a prompt.

## Troubleshooting

- If the screenshot button is disabled, start Runtime Preview first.
- If full preview capture misses content, check whether the preview is inside an iframe or a page that blocks full-page capture.
- If drawing feels wrong, use select mode to move, resize, duplicate, or delete existing annotation items.
- If export saves somewhere unexpected, use the save dialog to choose a folder and filename.
