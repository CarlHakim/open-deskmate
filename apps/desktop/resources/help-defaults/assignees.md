# Assignees

Assignees are people who work on budget projects, Chat projects, Build presets, or related work items.

They are not AI agents.

## When To Use It

Use assignees when you want to record which people are responsible for work inside a budget project, Chat project, Build preset, work item, or session.

## Quick Steps

1. Open **Project Management**.
2. Select a budget project.
3. Open the **Assignees** tab.
4. Create people in the directory if they do not exist yet.
5. Add default assignees to the budget.
6. Override assignees on specific Chat projects or Build presets when needed.
7. Review the overview to see who is working on what.

## Step-By-Step: Override Assignees For Work

1. Open **Project Management**.
2. Select the budget project.
3. Open the **Work** or **Assignees** tab.
4. Find the Chat project or Build preset.
5. Choose inherit, specific assignees, or explicitly no assignees.
6. Save the change.
7. Check the assignee overview to confirm the effective assignment.

## People Directory

Use the Assignees tab in Project Management to create and manage people.

Each person can have:

- Name.
- Role.
- Email.
- Phone.
- Company.
- Notes.
- Color.
- Active or archived status.

## Budget Defaults

A budget project can define default assignees.

Chat projects and Build presets inherit those people unless they override the assignment.

## Overrides

For a Chat project or Build preset you can choose:

- Inherit budget assignees.
- Choose specific people.
- Explicitly no assignees.

Build sessions inherit from their Build preset when possible.

## Overview

The Assignees overview shows:

- Person details.
- Active budgets.
- Chat projects.
- Build presets.
- Build sessions.
- Task and run counts.
- Usage totals where available.

## Owner Vs Assignees

The budget **Owner** is the internal person responsible for the budget or client relationship.

Assignees are the people doing the work.

## Troubleshooting

- If a person does not appear in selectors, check whether they are archived.
- If a Chat project or Build preset shows different people from the budget, it may have an override.
- If nobody should be assigned, choose the explicit no-assignees option rather than inherit.
- If usage totals are missing, confirm the related tasks or sessions are attached to the budget project.
